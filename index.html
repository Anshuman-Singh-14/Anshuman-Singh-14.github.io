Featured project

SentinelLite

Live at sentinellite.com

A containerized security platform that audits a network, matches what it finds against known CVEs, ranks the risk, and suggests fixes. Built as my capstone project.

  • Async network auditing. Scans hosts and services concurrently in Python, cutting full-subnet audit time by 65% across 50+ hosts.
  • Risk scoring. Maps discovered service versions to CVE data and ranks 200+ findings per scan using CVSS v3.1 and OWASP Top 10.
  • Auto-remediation. An LLM module generates context-aware fix snippets, shown in a TypeScript dashboard.
  • Microservices. Docker services behind an Nginx reverse proxy, so the whole platform starts with one command.
